# 🤖 AI Chatbot

A simple and interactive AI Chatbot built using HTML, CSS, JavaScript, and the Gemini API.

## 🚀 Features

- Interactive chatbot interface
- AI-generated responses
- Clean and responsive design
- User and bot message display
- Enter key support
- Typing indicator
- Mobile-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Gemini API
